# Changelog

## 1.1

- Signed automatic updates from GitHub Releases with a Check for Updates menu and update settings. Installation waits for file operations and a successful workspace save.
- Saved connection chooser in Cmd-K, clear Save Connection/Save and Connect actions and endpoint details in the sidebar.
- Saved SMB/WebDAV custom ports, shares and paths survive profile switching; typed credentials are cleared when switching profiles or authentication modes.
- Font families, wider file/icon size ranges, independent navigation fonts/icons and adjustable sidebar width.
- Appearance sharing across tabs, panes and windows on by default, with persistent individual-tab styling when disabled.
- Original Ocean, Forest, Sand and Plum palettes alongside the native System theme, each supporting light and dark modes.

Version 1.0 requires one manual DMG upgrade to 1.1 to gain the updater. Development and UI test builds cannot install production updates.

## 1.0

First public release of Commander4Mac.

- Two independent panes, tabs, locked/navigable pins, favorites and a shared shelf.
- List/icon views, System/Light/Dark themes, text and icon sizing, and workspace restoration.
- Queued local copy/move, conflict handling, cancellation, metadata preservation, rename, new folders and Trash.
- Quick Look, Open With, file clipboard actions and keyboard navigation.
- SFTP, SMB and HTTPS WebDAV connections with local/remote file and folder copies.
- Blue/teal folded-pane icon, drag-to-Applications DMG and Full Disk Access setup guidance.
- Developer ID signing, app/DMG notarization, bundled third-party notices and LGPL corresponding source.

Known limitations and exact coverage are recorded in [verification](docs/verification).
